History and foreword

StereoUtils_Py is a port of Stereo_V19 (StereoOSX_x.f95 + a family of companion Fortran files — stereograph.f, plotstereo.f95, pmagoutils.f…), a Fortran/Qt5 stereonet and directional-statistics application from the same paleomagnetism laboratory (Géosciences Rennes) as its sibling applications STARpaleomag_Py and AMS_Py. Where those two process specimen measurements and anisotropy tensors, StereoUtils_Py is the general-purpose directional statistics toolbox: the stereonet itself (Wulff/Schmidt projections, "layers" of directions/means/great circles), the Fisher-family statistical tests, structural (bedding/borehole/fold) corrections, and a large collection of VGP/paleolatitude/rotation utilities that the original Fortran grouped under "Pmag Utilities".

One menu, PmagPy-tools, is not a port at all: rather than reimplement routines the Fortran itself only shelled out to (writing a file, then invoking a standalone PmagPy command-line script — plot_map_pts.py, incfish.py, foldtest.py…), this port calls the installed pmagpy Python package's own functions directly. Same numerical results, no intermediate files or subprocess.

Two more menus, K-T and Hysteresis, are a port of a different companion Fortran program, Curie_OSX (susceptibility-vs-temperature and hysteresis-loop processing) — plotted directly with matplotlib rather than through the pixel-matched plotlib primitives the rest of the app uses. Pmag Utilities → Site Map is new work with no Fortran precedent at all: exporting .prmag site coordinates to KML/GMT/matplotlib maps.

Open source. The source code is available on GitHub alongside STARpaleomag_Py and AMS_Py. As with its sibling applications, researchers and students wishing to use or modify this program are encouraged to do so through Claude.

Data formats

StereoUtils_Py works with several small, independent in-memory lists rather than one unified project: directions (dec/inc pairs, optionally with a symbol), means (dec/inc/α95, drawn with a confidence cone), and great circles (pole dec/inc, optionally with a sector). Each has its own load/manual-entry/list/delete commands under Data, and its own file format — a plain text file with dec/inc (and α95, for means) columns, either positional or with a self-describing header (column names on the first line, in any order — #dec inc a95 or #site dec inc alpha95 are both read correctly). Every file reader in the app follows this same header-or-positional convention.

Beyond these three lists, two file-based systems layer on top: the Project system (a multi-"layer" file combining directions, means and great circles with per-entry symbol/color/size, meant to be hand-edited in a text editor — see Stereo Project file format below) and VGP handling (paleomagnetic pole positions, plotted on a world map rather than the stereonet — either loose dec/inc-as-lon/lat pairs via Plot VGPs on Map, or a full VGP project block with per-point symbol/color and dp/dm confidence ellipses).

Shared file with STARpaleomag_Py. The Stereo Project format is written directly by STARpaleomag_Py's own export results to Stereo_Py (menu File), so a site's specimen fits, site mean, and VGP can all be reviewed here without any manual reformatting — see the reference section for the exact column layout.

Typical session flow

Two common flows, depending on where the data comes from:

  1. LoadData → Load from file, or Manual entry
  2. PlotGraphics → Plot stereo
  3. TestStatistics → Fisher Statistics… (or another test)
  4. ExportGraphics → Export SVG…

…or, coming from STARpaleomag_Py with an already-exported project file:

  1. LoadGraphics → Load Project…
  2. PlotGraphics → Plot stereo project
  3. MapGraphics → Plot VGP Project…
  4. RetouchEdit symbol/color/info by hand in the project file, reload
Almost no keyboard shortcuts. Unlike STARpaleomag_Py/AMS_Py, nearly every command here is menu-only — the one exception is Hysteresis → Normalize Plot (Cmd+N/Ctrl+Shift+N), the first shortcut added to this app.

Data directions, means, great circles

Build the three working lists (directions / means / great circles) that everything else — Graphics, Statistics — plots or tests.

File [D-I]...
Loads dec/inc pairs from a file into directions. Prompts for a path (between consecutive points, for the connecting arc drawn on the stereonet) and a symbol, applied to every point loaded this way.
File [D-I_TC]...
Same as above, but the file's columns are (dec, inc, strike, dip) — the tilt correction is applied before the direction is stored, so what ends up in directions is already tilt-corrected.
File [D-I-a95]...
Loads dec/inc/α95 rows into means — each drawn with its own confidence cone.
File [D-I-a95_TC]...
Same as File [D-I-a95]..., with a tilt correction (strike/dip columns) applied before storing.
File [great circle]...
Loads great-circle poles (glon, glat) into great circles, with an optional sector (ad1, ai1, ad2, ai2) restricting the drawn arc — otherwise the full circle is drawn.
Manual [D-I]...
Types dec/inc pairs in one at a time (loop, Escape to stop), appended to directions.
Manual [D-I-a95]...
Types dec/inc/α95 rows in one at a time, appended to means.
Manual [great circle]...
Types great-circle poles in one at a time, appended to great circles.
List-data
Lists everything currently in all three working lists — directions, means, great circles — with their index numbers, needed by the Delete commands below.
Delete D-I line...
Removes one entry from directions by its list number.
Delete D-I-a95 line...
Removes one entry from means by its list number.
Delete GC line...
Removes one entry from great circles by its list number.
Initialize...
Clears one or more of the three working lists, after confirmation.
Help Data (file headers)
Displays the accepted file layouts for each Load command above — column order, and the self-describing header names each reader recognizes.

Graphics plots, projects, VGP maps, export

Everything that draws something — the native stereonet, the Project/VGP-Project systems, projection settings, and SVG export — gathered into one menu (originally split across "Command" and "Projection").

Plot stereo
Draws the stereonet frame plus the current directions/means/great circles lists, in the canvas built into the window. This is the everyday plot command.
Plot stereo project
Draws whatever is currently loaded in the Project system (self.project_entries — see the Project menu) instead of the plain directions/means/great-circles lists: each entry keeps its own symbol, color and size, and consecutive same-layer directions are connected by great-circle arcs.
Plot VGPs on Map
Plots the current directions list on an orthographic world map (via PmagPy's ipmag.make_orthographic_map/plot_vgp) — dec/inc are read directly as VGP longitude/latitude, one shared marker color/shape for every point. Prompts for the map's center latitude/longitude.
Plot VGP Project...
Plots self.project_vgp_entries — the VGP block of whatever was last opened via Load Project... — on the same kind of world map, but with each VGP's own symbol/color, and its dp/dm confidence oval drawn around it whenever the underlying project file also recorded the sampling site's own lat/lon (see VGP block below); otherwise a plain circle of radius p95 is drawn instead. Requires having loaded a project with a VGP block first — it does not prompt for its own file.
Clear Screen
Clears the plot canvas.
Graph title...
Sets a title shown above the next Plot stereo/Plot stereo project plot.
Stereographic (Wulff)
Equal-angle projection.
Equal area (Schmidt)
Equal-area (Lambert azimuthal) projection — the default, and the one almost always used for paleomagnetic directions since it doesn't visually distort point density.
Pole of projection...
Sets the latitude/longitude the stereonet is centered on. la=±90 gives the usual polar (equatorial-net) view; any other value tilts the whole net to view around an oblique pole.
Diameter...
Sets the stereonet's drawn diameter, in centimeters.
Symbol size & color...
Sets the default symbol size (cm) used for newly loaded directions/means/great circles. Symbol shape follows the single character typed at load time (c/t/e/l/s — circle/triangle/star/diamond/square) rather than a separate global setting; color on the native stereonet follows open-vs-filled by hemisphere, not a chosen color (that per-entry color control is specific to the Project system — see Help Project below).
Export SVG...
Exports whichever plot is currently displayed to an SVG file. For Plot stereo and Plot stereo project specifically, the plot is re-rendered through a dedicated writer that faithfully reproduces the original Fortran's own SVG output (svgwriter.py, port of graphicsAWE.f95's svginit/svgplot/newlayer) rather than matplotlib's generic exporter — verified byte-for-byte against real historical exports of both:
  • a continuous trace (a confidence ellipse's 120 segments, for instance) is written as a single <polyline> — one selectable object — instead of matplotlib's one separate path per segment;
  • for Plot stereo project, every entry drawn from a given Project "layer" is additionally wrapped in its own <g id="layer name">, exactly like the original Fortran's newlayer.
Every other plot (K-T, Hysteresis, VGP maps, PmagPy-tools…) still exports via matplotlib's own savefig, unchanged.

Statistics Fisher family & structural tests

Directional statistics on the current directions/great circles lists — mostly native ports of the original Fortran's own routines (stereo_stats.py), independent of the PmagPy-backed tests under PmagPy-tools.

Fisher Statistics...
Fisher (1953) mean of the current directions (≥2 needed), with an optional angular cutoff to drop points too far from the mean before finalizing it. The resulting mean is appended to means. Port of ANGU.
Fisher Dir+GC...
Combined Fisher mean from directions and great circles together (McFadden & McElhinny 1988) — needs at least 3 entries between the two lists, with optional sector weighting on the great circles and a manual starting direction if no plain directions are loaded yet. Port of FISHGC.
Fisher recursive...
Like Fisher Statistics, but the outlier cutoff (default 20°, prompted) is applied recursively, re-trimming and re-computing the mean each pass, needs ≥3 directions. Port of angurecur.
Fisher Strati
Needs ≥3 directions. Rotates each direction (declination +90°) and replaces the great circles list with the resulting poles — a direct port of STRATI, side effect included (the original Fortran overwrites its own great-circle array the same way).
progressive Fold test...
Loads its own site-by-site data file (site, dec, inc, azimuth, dip — site column optional) independent of whatever is already loaded, and replaces directions with the set of directions unfolded at the percentage of tilt correction that maximizes clustering. Port of FOLDTEST.
Mean Inclination only
Needs ≥2 directions. McFadden & Reid (1982) inclination-only estimator: reports the arithmetic mean, the Arason-biased mean, the McFadden-unbiased mean, a precision parameter and α95. A native port (stereo_stats.mean_inclination_native), distinct from the PmagPy-backed Mean Inclination under PmagPy-tools (same statistical method, independent implementation).
smallcircles Intersect
Computes small-circle intersections from the first two or three entries currently in means — a limitation inherited directly from the original Fortran (intersect2), which only ever reads the first few mean directions rather than letting you pick which ones. Appends the intersection point(s) found to directions.
angular departure from a specific direction...
For each current direction, the angular distance ("ADM") from a user-supplied reference direction (default: the geographic axial dipole, dec=0/inc=90) — flagged with > when it exceeds twice the set's own angular standard deviation about that same reference ("STV", printed first). Renamed from the original Fortran's STDDIP label ("St Dev dipole") to describe what it actually reports: unlike Fisher Statistics, the reference is fixed by you, not the data's own Fisher mean.
Reversal angle...
Compares the current directions against a user-given expected normal-polarity direction and reports the angle each one departs by. Port of reversalangle.
difference angle...
Reads a file of direction pairs (D0, I0, D1, I1) and reports the angle between each pair, one line per row. Port of difangle.

Project multi-layer symbol/color system

A separate in-memory list, self.project_entries — directions, means and great circles together, each with its own hand-editable symbol, color and size, grouped into named "layers". Independent of the plain directions/means/great circles lists under Data. The plotting commands for this system (Plot stereo project, Plot VGP Project...) now live under Graphics, alongside the rest of the plotting commands.

Load Project...
Loads a project file into self.project_entries — and, if the file has a # VGP block (the newer 3-block format written by STARpaleomag_Py, see reference below), its VGP entries too, into self.project_vgp_entries, ready for Graphics → Plot VGP Project... without loading anything a second time. An older, plain (no # block markers) project file loads exactly as before, with no VGP entries.
Export to Project
Builds self.project_entries from whatever is currently in the plain directions/means/great circles lists (Data menu) — the reverse direction from Load Project — and offers to save the result to a file. A quick way to get an existing plain selection into the Project system's per-entry symbol/color model.
List Project
Prints every entry currently in self.project_entries, one line each, in the exact column layout a project file uses — convenient to copy straight into a text file.
Init Project
Clears self.project_entries.
Fisher Project...
Computes a Fisher mean for each group of consecutive same-layer lines in self.project_entries (not a global group-by-layer — a layer name reappearing later in the file after a different layer starts a separate group), with an optional angular filter. Prints ready-to-paste project-file lines for each mean. Port of fisherproject.
Help Project (colors & symbols)
Displays the project file's column layout, the recognized symbol codes (c/t/e/l/s), and the accepted color formats — an R_G_B triplet (0–255 each) or one of about twenty named colors (red, blue, skyblue…).

Pmag Utilities VGP, rotation, correction toolbox

A large collection of mostly-independent, mostly-interactive calculators (native ports of pmagoutils.f, via stereo_pmagutils.py), organized as submenus matching the original Fortran's own groupings. Each one is self-contained — none of them read or write the Data/Project working lists, with the few exceptions noted below.

VGP conversions

Direction to VGP...
Given a site lat/lon, converts typed dec/inc (optionally with α95) into a VGP lat/lon (and dm/dp, if α95 given), one at a time in a loop.
File: Direction to VGP...
Batch version: reads a file of site lat/lon/dec/inc(/α95) rows (header-aware, or degree/minute/second coordinate columns) and converts every row.
VGP to direction...
The inverse of Direction to VGP: given a site lat/lon, converts a typed VGP lat/lon(/α95) back into the expected dec/inc(/dD,dI) at that site.
File: VGP to direction...
Batch version of the above, with a prompt for whether the file gives VGP lat-then-lon or lon-then-lat when no header names the columns.

Rotation/flattening tests

Rotation obs=DI Pole Ref...
Given an observed direction (dec/inc/α95), a site lat/lon, and a reference paleopole (lat/lon/p95), computes the direction expected from that pole, plus the rotation and flattening (with uncertainties) needed to reconcile the observed direction with it.
Rotation obs=DI DI Ref...
Same rotation/flattening calculation, but between two directly-given directions (each its own dec/inc/α95) rather than a direction and a pole.
Rotation obs=Pole Pole Ref...
Rotation and pole displacement between an observed pole and a reference pole (each lat/lon/A95), evaluated at a given site.

Paleolatitude

Paleolatitude at one site (file)...
Reads an apparent polar wander path file (age, VGP lat, VGP lon, optional α95) and, given one site's lat/lon and its expected polarity, computes paleolatitude through the time range covered by the file.
Inclination a95 to Plat and err...
Converts a single inclination + α95 directly to a paleolatitude with min/max error bounds, without needing a full APWP file.

GMT rotation export

Rotation vers GMT plot...
The most involved item in this menu: reads a site data file and a reference-APWP file, then over a chosen age range computes rotation vectors and their uncertainty ("pie") for each age step, writing .res/.vec/.pie files ready to feed into a GMT plotting script.
Aide Rotation
Static help text describing the file formats Rotation vers GMT plot expects.

Site Map

prmag to KML (Google Earth)...
Reads a .prmag file (its own minimal reader, specimen/site/lat/lon plus strike/dip/geologic type/lithology/age from the site's first specimen) and writes a Google Earth KML — one placemark per site, coordinates averaged across the site's specimens, styled to match the original Fortran KML output (bold field labels, line breaks, the same styleUrl).
prmag to GMT map script...
Same site list, written instead as a ready-to-run GMT6 script: gmt coast with shaded-grey continents, blue lakes/rivers, borders — no topography. GMT has no roads database, so a commented block explains how to add a Natural Earth roads file by hand. Site labels are decluttered automatically (a small spiral-nudge algorithm) into companion _sites.txt/_labels.txt/_leaders.txt data files.
Plot sites (matplotlib)...
The same sites plotted directly in the app's own canvas. With Basic basemap checked, adds coastlines/borders/roads/cities via Cartopy (falls back to a plain scatter plot with the real error message shown if Cartopy or its map data isn't available) — click-and-drag to zoom, double-click to reset.
Basic basemap (coastlines, roads, cities)
Checkbutton toggling whether Plot sites attempts the Cartopy basemap at all.

Core/bedding corrections

Core correction...
Borehole/drill-core orientation correction: given the corer's own dip and strike, corrects each typed dec/inc for it.
Bedding correction...
Standard tilt (bedding) correction, given either strike-and-dip or dip-direction-and-dip (auto-detected/converted), applied to typed dec/inc pairs.
inverseBedding cor...
The inverse problem: given both the in-situ and the already tilt-corrected D/I for the same direction (typed, or a file of d1 i1 d2 i2 rows), solves for the strike/dip that produces that exact correction.

Fold plunge

Fold plunge...
Corrects a direction for a plunging fold axis, given the strike/dip and the fold's own azimuth/dip — either a single first-order correction, or a progressive/iterative one.
File Fold plunge...
Batch version: reads a file of (site, dec, inc, α95, strike-or-dipdir, dip, fold azimuth, fold dip) rows and replaces directions with the corrected results.

Euler rotation

DI Polar rotation...
Rotates a typed dec/inc about a given Euler pole (lon/lat/angle), at a given site, one at a time in a loop.
VGP Plate rotation...
Batch version: rotates VGPs from a file, each row carrying its own Euler pole.

Paleointensity

mean paleointensity...
Weighted mean of paleointensity triples (F, Q, N — intensity, quality/weight, count), typed one at a time, or from a file — which can now be a real .pmagint (STARpaleomag_Py/AMS_Py's shared paleointensity archive, auto-detected from its tab-separated header) as well as the old plain 3-column format. For a .pmagint, every line is listed with an index and its H/ANI(sotropy-corrected)/cool(ing-corrected) values, and a range (i j) is selected before computing — repeatable on the same file without reopening it. The result table then reports all three variants (raw/aniso-corrected/cooling-corrected) side by side, matching the original Fortran's own three-row table. The old plain-format file keeps its original behavior: the whole file averaged in one shot, no selection step.
VDM and VADM...
Converts paleointensity + site latitude + inclination into the virtual dipole moment and virtual axial dipole moment.
VDM to Intensity...
The inverse of VDM and VADM: relocates a given VDM to the equivalent field intensity at a chosen latitude/inclination.
Relocate D I F...
Batch file relocation of paired direction+paleointensity data (site, age, lat/lon, dec/inc/α95, intensity+error) to a common target lat/lon, for comparing results from different sites/latitudes on equal footing.

IGRF

valeur CMT IGRF...
Computes the IGRF field (D, I, F, H, N, E, Z components) at a given lat/lon/year/altitude, via the ppigrf package. Reports clearly if ppigrf isn't installed rather than failing silently.
Help calcul IGRF
Static help text for the IGRF calculator above.

Other

conversion units...
Menu-driven unit converter for common magnetic units: Am²↔emu, Am²/kg↔emu/g, A/m↔emu/cc, Tesla/µTesla↔A/m.
test overprint...
Given an overprint direction plus the in-situ normal- and reverse-polarity directions it's contaminating, estimates the percentage of overprint and returns the corrected characteristic directions.
test flattening...
Applies the standard inclination-shallowing correction (tan(Icorrected) = f · tan(Iobserved)) to typed inclinations, one at a time in a loop.

PmagPy-tools calls the real PmagPy package

Not a port — the original Fortran routines behind this menu only ever wrote a file and shelled out to a standalone PmagPy script; this menu calls the installed pmagpy package's own functions directly (stereo_pmagpy.py). Bootstrap ellipse is new work: the Fortran's own equivalent routine has its random-number generator disabled in the source (a confirmed bug, not reproduced here), so this uses PmagPy's real bootstrap instead.

Fisher
Fisher (1953) mean of the current directions via PmagPy's own pmag.fisher_mean — no mode separation (normal/reverse), unlike Statistics → Fisher Statistics's native ANGU-based equivalent.
Bootstrap ellipse
Non-parametric (or parametric) bootstrap confidence ellipse on the current directions, fitting a Kent distribution via PmagPy's ipmag.mean_bootstrap_confidence/plot_bootstrap_confidence — needs ≥3 directions; prompts for the number of resamples.
Find Elongation
Bootstrap estimate of the elongation/inclination relationship in the current directions, via PmagPy's ipmag.find_ei — used to detect and correct inclination shallowing in a population of directions.
Reversal antipodality
Bootstrap reversal test on the current directions (split by polarity), via PmagPy's ipmag.reversal_test_bootstrap.
Test common mean
Bootstrap test of whether two direction sets could share a common true mean, via PmagPy's ipmag.common_mean_bootstrap.
Fold Test
Bootstrap fold test (optimal unfolding percentage with confidence bounds) via PmagPy's ipmag.bootstrap_fold_test — distinct from Statistics → progressive Fold test's native, non-bootstrap equivalent.
Mean Inclination
McFadden & Reid (1982) inclination-only mean via PmagPy's pmag.doincfish — same method as Statistics → Mean Inclination only, independent implementation.

K-T susceptibility vs. temperature (Curie_OSX)

Port of Curie_OSX's susceptibility-vs-temperature routines (curie_kt.py) — reading raw .CUR/.CLW instrument files, correcting for the furnace/empty-vessel contribution, normalizing, and estimating the Curie point. Plotted directly with matplotlib (square aspect), not through the pixel-matched plotlib primitives.

Open .CUR/.CLW File...
Reads one raw instrument file directly (temperature + susceptibility columns; the file's other columns — CSUSC/NSUSC — are never populated by the acquisition software and are ignored).
Open Sample List...
Reads a sample list (filename susceptibility mass zerodia [empty_vessel] per row): susceptibility=0 means normalize by mass; a nonzero value is an independent bulk-susceptibility anchor (already in SI, no unit conversion applied); zerodia=999 means use a full empty-vessel correction curve (named in the last column) instead of a constant.
Select File from List...
Browses the loaded sample list one entry at a time, applying whichever correction/normalization that entry specifies and plotting the result — the same "step through and pick" pattern used by the AGM/VSM/Hysteresis sample lists.
Furnace Correction
Subtracts the empty-vessel's own diamagnetic curve from the loaded sample's curve — either a constant (zerodia value) or, for zerodia=999, a smoothed heating/cooling lookup table built from the named empty-vessel .CUR file.
Normalize by Mass / Normalize by Volume
Normalizes susceptibility either by the sample mass (mg, giving SI mass-susceptibility) or by an independent bulk-susceptibility anchor read from the sample list (SI volume susceptibility) — whichever the sample-list entry called for.
Curie Point (2nd derivative)
Estimates the Curie point separately for the heating and cooling branches (split at the maximum-temperature index) via the second-derivative-maximum method — despite the original Fortran's own name for this routine ("tauxe"), it is not the literal Tauxe et al. (1996) two-tangent method.
Plot K-T
Square-aspect plot of the curve (heating solid red, cooling dashed blue), with the two Curie-point estimates marked as vertical dotted lines.

Hysteresis AGM / VSM / VFTB loop processing (Curie_OSX)

Port of Curie_OSX's hysteresis-loop routines (curie_hyst.py): paramagnetic/diamagnetic slope correction and Ms/Hc/Mr/Hcr extraction, verified field-by-field against the original Fortran's own historical results log for a real specimen. Three real instrument formats are supported, each with its own reader.

Open AGM Sample List... / Open VSM Sample List...
Loads a sample list (id mass_mg for AGM; index id mass_mg for VSM) alongside the matching raw data files in the same folder — AGM: <id> (full loop) + <id>-r (remanence/DCD curve); VSM: <id> - 1.csv + <id> - 2.csv. The instrument's own slope-corrected VSM export (... Corrections.csv) is deliberately not used — the raw file is always re-corrected by this same pipeline, for consistency between formats.
Select Sample to Plot...
Steps through the loaded AGM/VSM sample list, computing and plotting each one.
Open VFTB File...
A third format (Petersen Instruments VFTB, .hys) with no sample list at all: the specimen name and mass are already in the file's own header line, so one file opens and plots directly. A leading "virgin curve" segment some VFTB exports record before the actual loop (field ramping up from ~0 rather than starting near saturation) is detected and stripped automatically — left in, it corrupts the paramagnetic-slope fit. A "simple" VFTB file (one loop, no separate remanence/DCD curve) still reports Ms/Hc/χpara normally; Hcr/Mr are left unavailable rather than guessed.
Paramagnetic Fit Threshold...
Fraction of the maximum field (default 0.7) above which a point counts as "high field" for the paramagnetic slope fit — a real adjustable setting in the original program, not a fixed constant, and the exact historical value used for any one dataset generally isn't recoverable.
Normalize Plot (Cmd+N / Ctrl+Shift+N)
Each of the three plotted curves (raw loop, slope-corrected loop, remanence/DCD) is normalized independently, by its own maximum — not a single shared reference — so each saturates near ±1 regardless of the other two. The one keyboard shortcut in this application.
Click the X-axis
Not a menu item — clicking the plot's X-axis (line, ticks, or label) prompts for a new maximum field, rescaling the plot symmetrically.
PmagPy cross-check
After computing a result from any of the three formats, a second, independent estimate from PmagPy's own modern hysteresis pipeline (pmagpy.rockmag.process_hyst_loop — gridding, centering, instrument-drift correction, closure/saturation tests) is shown alongside it: Ms, Bc, χHF, Mr, Brh, plus whether PmagPy's own tests consider the loop closed/saturated. Not a replacement for the native result (a different algorithm) — a sanity check displayed next to it. Silently skipped (with a note) if pmagpy isn't installed.

Stereo Project file format reference

A plain text file, hand-editable in any text editor — the whole point of the Project system is that symbol, color and size are things you set by eye, not compute. Two variants exist: the original flat format (one list, positional columns, no header — still read and written exactly as before by Load/Export to Project), and the newer 3-block format written by STARpaleomag_Py's own Stereo_Py export, which groups entries into three self-labeled sections, each with its own column header. Load Project... auto-detects which one a file is and reads it accordingly.

# individual directions

One row per specimen-level result — a line (type=d, a point) or a plane (type=g, a real great circle, not just its pole plotted as a point). layer groups rows by site, so Fisher Project can recompute a site mean directly from them.

ColumnMeaning
layer, idsite (or other grouping name), specimen id
typed direction, or g great circle (dec/inc = pole)
dec, incdirection, or the plane's pole for type=g
alpha95unused for d; must be non-zero for g to load correctly — see callout below
tilt_correction0–100, MagIC-style (0 = in-situ, 100 = full tilt correction) — the orientation this row's dec/inc was computed in
symbol, color, sizeper-row plotting style — symbol code (c/t/e/l/s), a named color or R_G_B triplet, size in cm
infofree text, left blank by the exporter — yours to fill in by hand
alpha95==0.0 quirk. Inherited from the original Fortran loadproject: a row whose alpha95 reads exactly 0.0 is forced to type=d on load, whatever the file actually says — a plane written with alpha95=0 would silently lose its great circle and plot as a point instead. STARpaleomag_Py's exporter avoids this by writing the fit's own MAD there for a plane row rather than 0.0.

# mean directions

One row per site mean, always type=m (drawn with its α95 confidence cone) — same columns as the directions block, minus type, plus n (specimen count).

# VGP

One row per site pole — a geographic point (paleo-longitude/latitude), plotted on a world map via Graphics → Plot VGP Project..., never on the stereonet (a VGP isn't a local direction).
